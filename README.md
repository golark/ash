Convert natural language to shell commands fast, local & free ( No Subscriptions, No API Calls )

![Demo](./demo/demo.gif#autoplay)

### Install
```bash
brew tap golark/ash
brew install ash
```

Source the widget in your `.zshrc`:
```bash
source /path/to/ash/widget.zsh
```

Press `Ctrl+G` to generate a command from your input
